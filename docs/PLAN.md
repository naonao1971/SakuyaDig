## ひとことで
城下町の地下を掘り進め、忍具と落石で敵をかわしながら、埋まった CNP 11体を掘り出して地上へ戻る。

## 遊び方
- 目的: 3層（城下町の地下 → 金山の坑道 → 天守の地下蔵）に埋まった CNP 11体を掘り出し、地上に戻る
- ミス: 敵に触れる／落ちてきた岩に当たる
- クリア: 11体そろえて地上の出口にたどり着く
- 1プレイの長さ: 3分くらい
- 難しさ: 最初の層はやさしく、深くなるほど敵が速く・多くなる

## 操作
| | PC | スマホ（横持ち） |
|---|---|---|
| 移動（掘る） | 矢印 / WASD（4方向） | 左半分のスティック（4方向） |
| ボタン1: 忍具 | X（長押しで縛りきる） | 右下の〇（長押し） |
| 一時停止 / 音 | P / M | 画面中央 / 🔊 |

- 岩は、真下を掘ると少し揺れてから落ちる（ボタンは使わない）
- 自動連射はなし

## CNP 11体
- 出し方: 各層の土の中に埋まっている（城下町の地下3体・金山の坑道4体・天守の地下蔵4体）。掘り当てると救出、ロスターが埋まる
- 全員そろえたとき: 地上の出口が開く。クリア時に全員救出ボーナス

## スコア
- 何で点が入るか:
  - 土を掘る: 1マス 10点
  - 忍具で倒す: 層ごとに 200 / 300 / 400点
  - 岩でつぶす: 1体 500点、2体まとめて 1,500点、3体以上 3,000点
  - CNP を掘り出す: 1体 300点
- ボーナス（クリア時、結果画面で内訳を見せる）: CNP 全員救出 5,000点＋残機 1機につき 1,000点
- 理論上の最高点（目安）: 掘る 約9,000＋敵 15体を岩で最大効率 約15,000＋CNP 3,300＋全員ボーナス 5,000＋残機 約3,000 ≒ 35,000点 → `maxScore`: 50,000（取りこぼしの余裕を見る）

## 演出・素材
- キービジュアル: 無（仮はタイトル画面。あとで用意）
- クリア動画 / ゲームオーバー動画: 無（あとで用意）

## kit の設定（決まったら書く）
- controls: stick（`stickDigital4`、左半分）、buttons: 忍具 `{ id: "tool", label: "X", keys: ["KeyX"], primary: true }`、autoFire なし
- lives / maxScore: `lives: { start: 3 }`、`maxScore: 50000`
- ランキング: 公式タイトルとして共通 GAS を使う。`_games` シートに dig の行を足し、総合に含める
- cutscenes / resultScreen / share: 仕上げで決める
